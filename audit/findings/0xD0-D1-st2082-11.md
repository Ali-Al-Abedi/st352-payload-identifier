# Byte 1 = `0xD0` / `0xD1` — SMPTE ST 2082-11:2019

**Spec source.** SMPTE ST 2082-11:2019 — *Carriage of 4320-line and 2160-line Source image formats and ancillary data on a Dual-link 12 Gb/s SDI*

**Scope.**

| Byte 1 | Mode | Image | Section | Table | Bit-depth set |
|--------|------|-------|---------|-------|----------------|
| `0xD0` | Mode 1 | 4320-line (8K, Y'CbCr/ICtCp 4:2:2/4:2:0 10-bit) on dual-link 12G-SDI | §4.7 | Table 3 | 10-bit only (0h, 1h) |
| `0xD1` | Mode 2 | 2160-line standard (4K, 4:4:4(:4) 10/12-bit) on dual-link 12G-SDI | §5.8 | Table 9 | 4 values valid (0h-3h) |
| `0xD1` | Mode 3 | 2160-line HFR (4K HFR, 4:2:2 / 4:2:0 / 4:2:2:4 10-bit) on dual-link 12G-SDI | §6.9 | Table 17 | 10-bit only (0h, 1h) |

D1h is shared between Mode 2 and Mode 3 — the mode is implied by the byte 3 sampling value (Mode 3 only carries 4:2:2 / 4:2:0 / 4:2:2:4 sampling per Table 10).

## Findings

| # | ID | Severity | Description | Fix |
|---|----|----------|-------------|-----|
| 1 | D0-prog-transport | **P1** | Byte 2 b7 must be 1 (progressive transport) per §4.7.2 — decoder labelled b7=0 as "Interlaced (invalid)" but did not raise a warning. | **Fixed** — added warning on b7≠1 in 0xD0. |
| 2 | D0-prog-picture  | **P1** | Same as #1 for byte 2 b6 (progressive picture). | **Fixed** — added warning on b6≠1 in 0xD0. |
| 3 | D0-link-reserved | **P1** | Byte 4 b7:b5 ∈ {2h-7h} not warned in 0xD0 (D1 already warned). | **Fixed** — added warning on `link >= 2` in 0xD0. |
| 4 | D0-b3-reserved   | **P1** | Byte 4 b3 not decoded as a field nor warned on b3=1 in 0xD0 — spec mandates b3=0. | **Fixed** — added field row + warning in 0xD0. |
| 5 | D0-mode1-bitdepth | **P1** | ST 2082-11 Mode 1 (D0h) Table 3 only allows 10-bit (b1:b0 ∈ {0h, 1h}) and explicitly states "Other values shall be reserved". Decoder displayed "Reserved" via `BIT_DEPTH_2BIT_NARROW` but did not raise a `warnings` entry. | **Fixed** — added `if (depth >= 0x2)` warning in 0xD0. |
| 6 | D1-prog-transport / picture / b3 | **P1** | Same b7/b6 must-be-1 and b3 must-be-0 missing in 0xD1. | **Fixed** — added the same set of three warnings in 0xD1. |

No P0 bugs uncovered. The Mode 2 / Mode 3 inference for D1h is informative (the spec doesn't explicitly say which sampling values map to which mode; this is inferred from Table 10 which lists Mode 3 image formats with sampling = 4:2:2 / 4:2:0 / 4:2:2:4 only).
