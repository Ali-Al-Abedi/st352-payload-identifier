## Findings

| # | ID | Severity | Description | Fix |
|---|----|----------|-------------|-----|
| 1 | hSamp footnote-5 | **P2** | Byte 3 b6 = 1 (DCI 2048/4096/8192) is not permitted for BT.2077-2 codes per Table 3-7 footnote 5 ("This bit should be set to '0' for all formats in Part 3 of this Recommendation"). The decoder previously accepted b6=1 silently and reported a DCI horizontal pixel array (e.g. 4096×2160 for 0xE0). | **Fixed** — added a warning in `make6Gor24GLayout` decode path: "Byte 3 b6 = 1 (DCI horizontal sampling) is not permitted for BT.2077-2 24G codes — Table 3-7 footnote 5 mandates b6 = 0 (1920/3840/7680)." |

No P0 / P1 bugs uncovered.

## Notes

- BT.2077-2 byte 4 has **no rate-conditional bit-depth restriction** (unlike ST 2081-10 Mode 3 / ST 2081-12 Mode 3). The factory correctly registers BT.2077-2 codes with `bitDepth12: true` (constant). HFR rates and 12-bit are both legal per Table 3-7.
- BT.2077-2's link order (0h=Link 1 … 7h=Link 8) is identical to the ST 2081-x/-30 family; no separate decoder needed.
- Table 3-8 also shows ST 2081-10/-11/-12 (`C0`/`C2`/`C5`) and ST 2082-10/-11/-12 (`CE`/`D1`/`D3`) for completeness; those codes are owned by their respective SMPTE specs and are audited under separate findings.
