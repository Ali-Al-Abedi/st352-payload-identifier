# Byte 1 = `0x90` / `0xA0` — SMPTE ST 435-1:2012

**Spec source.** SMPTE ST 435-1:2012 §7.3 Table 6 (quad-link, 0x90), §7.4 Table 9 (octa-link, 0xA0); source-format constraints from §6.3 Table 3, §6.4 Table 4; Tables 7 (sampling) and 8 (rate).

**PDF text extract.** `audit/pdf-text/st0435-1-2012.txt`
**Code under audit.** `vpid.html` lines ~1975-2098 (0x90), ~3035-3140 (0xA0).
**Status.** Fixed (1x P1 + 3x P2 issues found and patched).
**Auditor.** AI agent, 2026-05-08.

## Findings & fixes

| # | Severity | Codes | Description | Fix |
|---|----------|-------|-------------|-----|
| 1 | P1 | 0x90 | Picture-rate validity check `[0x9, 0xA, 0xB]` (50/59.94/60) was unconditionally applied. Per §6.3 Table 3 systems 4.2 and 4.3 (`2048x1080` ST 2048-2 RGB / RGB+A 10/12-bit), `47.95` (rate 4h) and `48` (rate 8h) progressive are valid when `byte 3 b6 = 1` (hSamp=1). | Made the allowed-rate set hSamp-dependent: `[0x9, 0xA, 0xB]` for 1920x1080, `[0x4, 0x8, 0x9, 0xA, 0xB]` for 2048x1080. |
| 2 | P2 | 0x90, 0xA0 | Sampling code `7h` fell back to global `SAMPLING` (Reserved). Per Table 7 of ST 435-1, 7h is "SMPTE ST 2048-2 FS1" (Color VANC packet). | Override the sampling label inside the 0x90 / 0xA0 decoders. |
| 2b | P2 | 0x90, 0xA0 | Reserved sampling values Bh/Ch/Dh/Fh produced no warning. | Added explicit `warnings.push(...)` for `samp ∈ {Bh, Ch, Dh, Fh}` citing Table 7. |
| 3 | P2 | 0x90, 0xA0 | `characteristics.scan` used `trans ? "Progressive" : "Interlaced"`, ignoring the picture bit (b6). PsF carriage (b7=0, b6=1) was reported as "Interlaced". | Compute `scan = pic ? (trans ? "Progressive" : "Progressive (PsF)") : (trans ? "Interlaced (transport mismatch)" : "Interlaced")`. |
| 4 | P2 | 0x90, 0xA0 | `decode -> encode` round-trip was broken — `encode()` expected raw numeric fields that `decode()` never set. | Added raw bit fields (`rate`, `samp`, `chAssignment`, `linkAssignment`, `depthBits`, `transBit`, `picBit`, `hSampBit`, `aspectBit`) and made `encode()` prefer these numerics. |

## Bit-by-bit verification (key tables)

### 0x90 — Quad-link Table 6
- byte 2 b7/b6 transport/picture; b5:b4 Reserved; b3:b0 picture rate (Table 8) — verified
- byte 3 b7 Reserved; b6 hSamp 1920(0)/2048(1); b5 aspect 16:9(1)/Unknown(0); b4 Reserved; b3:b0 sampling (Table 7, with 7h = ST 2048-2 FS1) — verified
- byte 4 b7:b6 channel Ch1..Ch4; b5:b2 Reserved; b1:b0 bit depth 8/10/12, 3h Reserved — verified

### 0xA0 — Octa-link Table 9
- Word 2 / Word 3 same as Table 6 — verified
- byte 4 b7:b5 channel Ch1..Ch8 (3-bit); b4:b2 Reserved; b1:b0 bit depth — verified

## Notes

- `BIT_DEPTH_ST435` correctly excludes Full-Range labels (ST 435-1 §7 has no FR/NR distinction). §7 note that 12-bit values are mapped into a 10-bit interface is informational and not signalled in the VPID.
- Encoders never write the Reserved bit positions; they emit `0`. Receivers seeing those bits set should warn — and the decoder does.

## Sign-off

- All decode fields trace to a verbatim line in the spec.
- All encode fields produce bytes that match the spec; round-trip is byte-perfect for canonical inputs.
- All Reserved values produce a warning.
- All allowed-rate / allowed-sampling subsets enforced (now hSamp-aware for 0x90).
- Round-trip vectors cover every bit position at least once across the two codes.
