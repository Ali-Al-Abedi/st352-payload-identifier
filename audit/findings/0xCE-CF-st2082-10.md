## Findings

| # | ID | Severity | Description | Fix |
|---|----|----------|-------------|-----|
| 1 | CE-prog-transport | **P1** | Byte 2 b7 must be 1 — decoder labelled b7=0 as "Interlaced (invalid)" but did not raise a warning. | **Fixed** — added warning on b7≠1. (Inherited by 0xCF.) |
| 2 | CE-prog-picture  | **P1** | Same as #1 for byte 2 b6. | **Fixed** — added warning on b6≠1. (Inherited.) |
| 3 | CE-link-reserved | **P1** | Byte 4 b7:b5 was not decoded as a field at all. Spec mandates b7:b5 = 0h ("Single link 12G-SDI"); other values reserved. | **Fixed** — added field row + warning on b7:b5 ≠ 0h. (Inherited.) |
| 4 | CE-b3-reserved   | **P1** | Byte 4 b3 was not decoded as a field nor warned on b3=1. Spec mandates b3 = 0. | **Fixed** — added field row + warning on b3=1. (Inherited.) |

No P0 bugs uncovered. 0xCF correctly inherits all fixes via `VPID_LAYOUTS[0xCE].decode()`.
